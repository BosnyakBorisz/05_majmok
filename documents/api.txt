Erőforrásaink: majom, banán
 
 
Adatok
 
monkeys (tömb, kezdetben 3 majom)
  id       – szám, a szerver osztja ki
  name     – szöveg, kötelező
  sex      – szöveg, kötelező (pl. male, female)
  species  – szöveg, kötelező (pl. gibbon, gorilla, orangutan)
 
bananas (tömb, kezdetben 4 banán)
  id       – szám, a szerver osztja ki
  color    – szöveg, kötelező (pl. yellow, green)
  sweet    – logikai (true / false), kötelező
  monkeyId – egész szám vagy null; egy létező majom id-ja, null = nincs gazdája
 
globalMonkeyId – a következő kiosztandó majom-id (monkeys.length + 1)
globalBananaId – a következő kiosztandó banán-id (bananas.length + 1)

 
Monkeys – CRUD route lista
GET /monkey – összes majom lekérdezése (READ).
GET /monkey/:id – egy majom lekérdezése azonosító alapján (READ).
POST /monkey – új majom létrehozása (CREATE).
PATCH /monkey/:id – meglévő majom módosítása (UPDATE).
DELETE /monkey/:id – majom törlése azonosító alapján, a hozzá tartozó banánokkal együtt.
 
Bananas – CRUD route lista
GET /banana – összes banán lekérdezése (READ).
GET /banana/:id – egy banán lekérdezése azonosító alapján (READ).
POST /banana – új banán létrehozása (CREATE); a monkeyId-nak létező majomra kell mutatnia.
PATCH /banana/:id – meglévő banán módosítása (UPDATE); a monkeyId-nak létező majomra kell mutatnia.
DELETE /banana/:id – banán törlése azonosító alapján (DELETE).
 
Egyéb
Bármilyen más útvonal vagy metódus – 404-es JSON hiba.


1. majmok oldal
   - Cím: GET /
   - Middleware lánc: getMonkeysMW, getBananasMW, renderMW('monkeyList')
   - Leírás: Megjeleníti az összes majmot és a hozzájuk tartozó banánok darabszámát.

2. új majom
   - Cím: GET /monkey/new
   - Middleware lánc: renderMW('monkeyForm')
   - Leírás: Megjeleníti az üres űrlapot új majom felvételéhez.

3. új majom mentése/küldése 
   - Cím: POST /monkey/new
   - Middleware lánc: createMonkeyMW, redirectMW('/')
   - Leírás: Elmenti az új majmot az adatbázisba, majd visszairányít a főoldalra.

4. majom szerkesztése űrlap
   - Cím: GET /monkey/edit/:id
   - Middleware lánc: getMonkeyMW, renderMW('monkeyForm')
   - Leírás: Megjeleníti a kiválasztott majom adataival előre kitöltött űrlapot.

5. majom módosítás 
   - Cím: POST /monkey/edit/:id
   - Middleware lánc: getMonkeyMW, updateMonkeyMW, redirectMW('/')
   - Leírás: Frissíti a majom adatait az adatbázisban, majd visszairányít a főoldalra.

6. majom törlése
   - Cím: GET /monkey/delete/:id
   - Middleware lánc: getMonkeyMW, deleteMonkeyBananasMW, deleteMonkeyMW, redirectMW('/')
   - Leírás: Törli a majmot és az összes banánját, majd visszairányít a főoldalra.



7. banánok listája
   - Cím: GET /banana
   - Middleware lánc: getBananasMW, getMonkeysMW, renderMW('bananaList')
   - Leírás: Megjeleníti az összes banánt és a hozzájuk rendelt majmok nevét.

8. új banán
   - Cím: GET /banana/new
   - Middleware lánc: getMonkeysMW, renderMW('bananaForm')
   - Leírás: Megjeleníti az űrlapot és a majmok választólistáját (legördülő menü).

9. új banán mentése
   - Cím: POST /banana/new
   - Middleware lánc: checkMonkeyIdMW, createBananaMW, redirectMW('/banana')
   - Leírás: Elmenti az új banánt az adatbázisba, majd visszairányít a banánlistára.

10. banán szerkesztése
    - Cím: GET /banana/edit/:id
    - Middleware lánc: getBananaMW, getMonkeysMW, renderMW('bananaForm')
    - Leírás: Megjeleníti a banán adataival kitöltött űrlapot és a majomválasztót.

11. banán módosítás küldése
    - Cím: POST /banana/edit/:id
    - Middleware lánc: getBananaMW, checkMonkeyIdMW, updateBananaMW, redirectMW('/banana')
    - Leírás: Frissíti a banán adatait az adatbázisban, majd visszairányít a banánlistára.

12. banán törlés
    - Cím: GET /banana/delete/:id
    - Middleware lánc: getBananaMW, deleteBananaMW, redirectMW('/banana')
    - Leírás: Törli a banánt az adatbázisból, majd visszairányít a banánlistára.
